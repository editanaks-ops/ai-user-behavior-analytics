## Overview

AI User Behavior Analytics is a case study based on an internship project focused on analyzing user behavior, psychotype identification, personalization, and sales support.

The project explored how website interactions can be transformed into behavioral signals, personalized communication, and actionable insights for managers.

## My Contribution

* Conducted UX and behavioral analysis of the website.
* Evaluated the quality and availability of behavioral signals for psychotype detection.
* Identified limitations in user interaction patterns affecting classification accuracy.
* Developed and tested the `personal_text_generator` module for personalized messaging.
* Adapted communication based on psychotype and confidence score.
* Participated in prompt testing and optimization.
* Contributed to the design of behavioral signal interpretation logic.
* Participated in Git workflow, commits, and pull requests.

## Key Areas

### Website Analysis

Analysis of user interaction patterns and identification of opportunities for improving behavioral signal collection.

### Personalization

Development of personalized communication scenarios based on psychotype classification and confidence levels.

### Behavioral Signals

Interpretation of user actions and the transformation of behavioral data into meaningful sales-support signals.

### Sales Support

Preparation of personalized recommendations and manager-oriented insights.
